## 💻 Windows Networking Commands

| Command | Purpose |
|---|---|
| `ipconfig` | Display IP configuration |
| `ipconfig /all` | Display detailed network information |
| `ipconfig /release` | Release DHCP-assigned IP |
| `ipconfig /renew` | Renew DHCP-assigned IP |
| `ping 8.8.8.8` | Test network connectivity |
| `tracert google.com` | Trace network route |
| `nslookup google.com` | Query DNS information |
| `hostname` | Display computer name |
| `netstat` | Display network connections |
